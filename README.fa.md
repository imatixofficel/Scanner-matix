# Matix — اسکنر IP کلادفلر و سازنده کانفیگ

> به نام خدا

یک ابزار وب سبک و بدون نیاز به build برای پیدا کردن IPهای تمیز کلادفلر و ساخت دسته‌ای کانفیگ‌های VLESS.

## ✨ ویژگی‌ها

- اسکن واقعی IP — هر ۱۵ دقیقه به صورت خودکار ۴۵۰۰+ آی‌پی کلادفلر با TCP + TLS واقعی تست می‌شه.
- نتایج زنده — نتایج به صورت JSON ذخیره می‌شن و مستقیم به frontend داده می‌شن.
- سازنده کانفیگ — چند کانفیگ VLESS رو با چند IP در یک کلیک ترکیب کن. UUID، پورت، TLS، SNI، path و همه پارامترها دست‌نخورده باقی می‌مونن.
- بدون نیاز به بک‌اند — کاملاً استاتیک، هاست‌شده روی GitHub Pages.
- رابط کاربری فارسی — چیدمان راست‌چین با فونت وزیرمتن.

---

## 🏗 نحوه کار

1. GitHub Actions هر ۱۵ دقیقه scanner.py رو اجرا می‌کنه.
2. اسکنر حدود ۴۵۰۰ آی‌پی از رنج‌های رسمی IPv4 کلادفلر نمونه‌برداری می‌کنه.
3. هر آی‌پی با TCP + TLS handshake واقعی روی پورت ۴۴۳ تست می‌شه.
4. ۲۰۰ آی‌پی برتر (مرتب‌شده بر اساس تأخیر) توی data/clean_ips.json ذخیره می‌شن.
5. frontend (app.js) این JSON رو می‌خونه و نتایج رو نمایش می‌ده.
