# Matix — اسکنر IP کلادفلر

به نام خدا 🤍
**IP‌های تمیز و سریع کلادفلر رو خودکار پیدا کن — هر ۱۰ دقیقه یه بار.**

🌐 **دموی آنلاین:** [https://imatixofficel.github.io/Scanner-matix/](https://imatixofficel.github.io/Scanner-matix/)

---

## این چیه؟

Matix یه ابزار ساده و رایگانه که IPهای سالم کلادفلر رو برای کانفیگ‌های VLESS، Trojan یا Shadowsocks پیدا می‌کنه.

پشت صحنه هر ۱۰ دقیقه بی‌سروصدا اجرا می‌شه، هزاران IP رو با TCP+TLS واقعی و درخواست HTTP تست می‌کنه، سرعت دانلود واقعیشون رو چک می‌کنه، و فقط اونایی که واقعاً زنده و سریعن رو نگه می‌داره.

هیچ داده جعلی، هیچ IP تکراری، هیچ API key. فقط IPهای تمیز و تست‌شده.

## چی بهت می‌ده؟

هر اسکن یه لیست ساختارمند مثل این بهت می‌ده:

json
{
  "ip": "104.25.195.64",
  "ms": 82,
  "status": "online",
  "colo": "SEA",
  "speed_mbps": 17.55,
  "persistent": false,
  "online_count": 1
}

· ⏱️ ms — سرعت پاسخ IP
· 🌍 colo — کدوم نقطه کلادفلر جواب داده (SEA، FRA، AMS و…)
· ⚡ speed_mbps — سرعت دانلود واقعی
· 💎 persistent — اینکه این IP ماندگار بوده یا نه

IPهای ماندگار 💎

بعضی IPها روزها یا حتی هفته‌ها سالم می‌مونن. Matix اینا رو خودکار تشخیص می‌ده.

اگه یه IP توی ۷ روز اخیر ۳ بار یا بیشتر آنلاین دیده بشه، به‌عنوان ماندگار علامت می‌خوره و توی سایت با 💎 نشون داده می‌شه.

IPهای ماندگار معمولاً پایدارتر و قابل‌اعتمادترن.

پشت صحنه چطور کار می‌کنه؟

هر ۱۰ دقیقه، Matix:

1. 🎲 ۷۵۰۰ IP از رنج‌های کلادفلر نمونه‌برداری می‌کنه
2. 🔌 هر کدوم رو با TCP + TLS واقعی تست می‌کنه
3. 🌐 با درخواست HTTP واقعی تأییدش می‌کنه
4. ⚡ سرعت ۱۰۰ تای برتر رو اندازه‌گیری می‌کنه
5. 🧹 تکراری‌ها رو حذف می‌کنه
6. 💎 IPهای ماندگار رو ردیابی می‌کنه
7. 💾 نتایج رو ذخیره می‌کنه
8. 📤 روی GitHub Pages منتشرشون می‌کنه

همه چیز روی GitHub Actions اجرا می‌شه — کاملاً رایگان.
